## Notes

- `Status` should use `completed` or `ended-early`.
- Rhythm fields apply when beat, metronome, or music timing is active.
- Directional fields are reserved for future directional error capture.
- Engagement fields are reserved for duration and pacing metrics once session timing is captured.
