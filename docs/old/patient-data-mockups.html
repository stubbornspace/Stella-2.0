Stella · Interface mockup

Reviewing patient data & trends

Illustrative screens for the hosted service where a clinician signs in, follows each child's exercise sessions over time, and where the practice owner sees activity across every clinic. These are static mockups to react to — layout and wording, not final visuals.

Sample data, not real patients. Every name, code and number here is invented. Figures are shown as performance measures (reaction time, accuracy, consistency) — never as a clinical or developmental outcome.

Mockup for review only. Screens and figures are illustrative; nothing here is connected to a real device or database. If the hosted service holds any information that identifies a child, health-privacy rules apply — the working plan is to store an anonymous code per patient and keep the name-to-code list with the clinic. See docs/cloud-architecture.md.
